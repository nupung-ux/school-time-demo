# 학교 통합 시간 관리 — 연수용 체험 사이트

이 저장소는 연수에서 선생님들이 기능을 직접 만져 보는 **체험 전용** 사이트입니다.
실제 학교 운영 화면은 들어 있지 않습니다. 접속하면 바로 "체험 방 고르기"가 나오고,
방을 만들면 24학급, 전담 5명, 외부강의, 특별실 예약, 보결, 개별지도가 들어간 상태로 시작합니다.

- 관리자 암호 / 개별지도 비밀번호: 1234
- 파일: timetable.html(프로그램), config.js(설정), manual.html(사용설명서)
- Vercel에 올리면 주소가 생깁니다. 방 자료는 config.js의 firebase 프로젝트에 저장됩니다.
