# 학교 통합 시간 관리

- timetable.html : 통합 시간표 (담임, 전담, 외부강의, 특별실, 보결, 개별학생 교육지원, 현황)
- index.html     : 월간운영계획 (학교 일정표)
- config.js      : 우리 학교 설정 (학교 이름, Firebase 연결 정보)
- manual.html    : 선생님용 사용설명서

설치 안내: 받은 사이트의 /install/ 페이지를 따라 하세요.
프로그램을 새 버전으로 바꿀 때는 timetable.html, index.html만 다시 올리면 됩니다 (config.js와 데이터는 유지).
